# 🔐 Tarea 07 - Generador de Contraseñas con Flutter

## 📝 Introducción
Este proyecto es una tarea de Flutter cuyo objetivo principal es implementar un generador de contraseñas dinámico utilizando widgets `StatefulWidget`. y libreria `random`

## 🎯 Requerimientos
- Crear una lista de tarjetas (`ListView`) donde cada tarjeta genere una contraseña de diferentes longitudes.
- Las longitudes de las contraseñas deben ser: `8, 12, 16, 20, 24, 28, 32, 36, y 40` caracteres.
- Cada tarjeta debe permitir:
  - Copiar solo la contraseña de su tarjeta.
  - Refrescar su contraseña sin afectar a las demás.
  - Resetear su contraseña individualmente con un icono.
- Dos botones globales deben permitir:
  - Generar nuevas contraseñas para todas las tarjetas.
  - Eliminar todas las contraseñas

## ⚙️ Instalación y Ejecución
Antes de ejecutar este proyecto, asegúrate de tener Flutter instalado y configurado.

### **1️⃣ Instalar Flutter**
Sigue la guía oficial según tu sistema operativo:
🔗 [https://docs.flutter.dev/get-started/install](https://docs.flutter.dev/get-started/install)

### **2️⃣ Clonar el Repositorio**
```bash
git clone https://github.com/victortelles/Flutter-pass_generator.git
```
```bash
cd Flutter-pass_generator
```

### **3️⃣ Instalar Dependencias**
```bash
flutter pub get
```

### **4️⃣ Ejecutar la Aplicación**
```bash

```
